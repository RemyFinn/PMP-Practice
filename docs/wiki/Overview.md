# 项目概览

PMP 做题系统是一套本地可运行、也可部署到服务器的刷题系统。它适合个人或少数朋友一起使用，每个人拥有独立的作答记录和错题集。

## 核心能力

- 四套模拟题练习：模拟七、模拟八、模拟九、模拟十。
- 混合随机练习：把四套题打乱后做题。
- 错题集：答错自动加入，点击“学会了”后移出。
- 思路总结：按解题思路查看题号，也可以打开题目直接练习。
- 题库管理：管理员可新增、编辑、删除题目。
- 多用户：管理员创建账号，普通用户独立保存作答和错题。
- 计时：记录每题作答用时。

## 数据隔离

全局共享：

- 套卷
- 题目
- 选项
- 标准答案
- 解析
- 思路总结

按用户独立：

- 作答记录
- 错题状态
- 错题次数
- 作答次数调整
