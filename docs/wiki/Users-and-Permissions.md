# 用户与权限

系统适合个人或少数朋友使用。账号由管理员创建，不开放注册。

## 角色

### 管理员

可以：

- 做题
- 查看思路总结
- 管理自己的错题集
- 管理题库
- 创建用户
- 禁用用户
- 重置用户密码

### 普通用户

可以：

- 做题
- 查看思路总结
- 管理自己的错题集
- 调整自己的错题次数和作答次数

不能：

- 编辑题库
- 创建用户
- 修改其他用户数据

## 数据归属

每个用户独立保存：

- 作答记录
- 错题状态
- 错题次数
- 作答次数调整

题库和思路总结是全局共享的。

## 初始管理员

系统启动时会读取环境变量创建初始管理员：

```env
FIRST_ADMIN_USERNAME=remy
FIRST_ADMIN_PASSWORD=change-me-now
FIRST_ADMIN_DISPLAY_NAME=Remy
```

如果该用户名已经存在，不会覆盖原密码。

## 创建朋友账号

管理员登录后进入“用户”页面：

1. 输入用户名。
2. 输入显示名。
3. 设置初始密码。
4. 选择角色，默认普通用户。
5. 点击创建。

## 禁用用户

在用户管理页关闭“启用”即可。禁用后该用户无法继续登录。
